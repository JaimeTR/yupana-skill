# Instituciones y fuentes de datos del Perú

> Cada entrada indica qué publica y qué verificar. **El acceso programático (API) y la gratuidad deben comprobarse en el portal oficial** antes de usarlos en un producto.

| Institución | Qué publica (alto nivel) | Acceso a revisar |
|---|---|---|
| **BCRP** (Banco Central de Reserva del Perú) | Series macro (BCRPData), Nota Semanal, Reporte de Inflación (trimestral), Informe de Estabilidad Financiera, programa monetario, tipo de cambio, tasas, reservas | BCRPData tiene API pública documentada (guía oficial para desarrolladores) |
| **INEI** | IPC, PBI mensual y trimestral, encuestas de hogares (ENAHO, ENDES), censos, pobreza, empleo (microdatos) | Portal de microdatos y reportes técnicos; la existencia de API pública debe confirmarse |
| **MEF** | Marco Macroeconómico Multianual, ejecución presupuestal (Consulta Amigable / SIAF), Transparencia Económica | Portales de transparencia y datos abiertos |
| **SUNAT** | Recaudación tributaria, comercio exterior (aduanas) | Estadísticas en su portal |
| **SBS** | Sistema financiero, tipo de cambio SBS, seguros, AFP | Estadísticas en su portal |
| **SMV** | Mercado de valores | Portal institucional |
| **MTPE** | Empleo formal, planillas | Portales de estadísticas |
| **OSCE** | Contrataciones públicas (SEACE) | Datos abiertos |
| **Plataforma Nacional de Datos Abiertos** | Conjuntos de datos del Estado | datosabiertos.gob.pe (verificar formatos y API) |
| **Banco Mundial, FMI, OCDE, CEPAL, BID** | Series comparables entre países | Banco Mundial: API pública |

## Calendario típico de publicación (verificar el calendario oficial)
- IPC: a inicios del mes siguiente.
- PBI mensual y PBI trimestral: con rezago de semanas a meses.
- Cuenta corriente y balanza de pagos: trimestral, con rezago.
- Reporte de Inflación: trimestral. Programa monetario: mensual.

## Advertencias
1. **Revisiones**: los datos recientes se corrigen. Guarda la fecha de consulta.
2. **Cambios de año base**: rompen la comparabilidad. Indica la base.
3. **Cobertura geográfica**: Lima Metropolitana ≠ Perú.
4. **Términos de uso**: respeta las condiciones de cada institución y cita siempre.
