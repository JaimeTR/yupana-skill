# Ejemplos de uso (qué pedirle al skill)

## Estudiantes
- "Necesito la serie mensual de [variable] de 2015 a hoy para mi tesis; guárdala con su cita y dime cómo citarla en APA."
- "Explícame la diferencia entre PBI real y nominal con un ejemplo de datos peruanos."
- "Redacta el capítulo de datos de mi tesis con estas variables y fuentes."
- "Revisa si mi interpretación de este coeficiente es correcta."

## Profesionales
- "Prepara el informe de coyuntura del mes con inflación, tipo de cambio y tasa de referencia."
- "Compara la inflación interanual con el rango meta en los últimos 24 meses y redacta tres conclusiones."
- "Verifica las cifras de este borrador contra las fuentes."
- "Haz una nota breve de una página sobre [variable] para un cliente."

## Docentes
- "Dame ejemplos peruanos recientes del efecto base para una clase."
- "Arma un ejercicio de variaciones porcentuales con datos reales y su solución."
