# Citas y trazabilidad

## Regla
Toda cifra lleva una cita que permita reproducirla.

## Qué incluir
| Campo | Ejemplo |
|---|---|
| Nombre de la serie | (el que da la fuente) |
| Código | (el de la fuente) |
| Fuente | BCRPData |
| URL de consulta | la que devuelve el script en `source.url` |
| Fecha de consulta | `source.retrievedAt` |
| Unidad y periodo | % interanual, mensual |
| Notas | preliminar, base, ajuste |

## En el texto
Cifra con número de nota: "… 3,2 % interanual [1]". En el anexo, tabla de fuentes.

## Cuando no hay dato
Escribir: "No se dispone de dato verificado para [variable] en [periodo]". Nunca estimar de memoria.

## Verificación antes de entregar
1. Lista todas las cifras del texto.
2. Contrástalas con la salida de los scripts.
3. Corrige o elimina las que no coincidan.
